بصمة الخادم (Server Host Fingerprint)

مفتاح التحقق من هوية السيرفر لمنع أي انتحال عبر الشبكة (Man-in-the-Middle).

⚠️
تنبيه أمني هام بشأن بصمة الخادم:

استخراج البصمة من السيرفر يعتمد على أول مصافحة عبر الشبكة. لضمان أمان خادمك التام، يجب عليك مطابقة البصمة مع شاشة لوحة تحكم Contabo أو سجلات الخادم المستقلة قبل تأكيد الربط.

مفتاح التشفير Ed25519 المخصص للنشر

يستخدم مفتاح Ed25519 عالي الأمان للتواصل بين أدوات النشر وخادم Contabo عبر مصادقة المفاتيح حصراً.

الخطوة 1: ربط حساب ومستودع GitHub

اربط حساب GitHub لتفويض تشغيل الـ Workflow وقراءة سجلات النشر بأمان.

الخطوة 2: ربط خادم Contabo

أدخل عنوان السيرفر والبيانات الأولية اللازمة لتهيئة بيئة التشغيل.

الخطوة 3: التحقق من بصمة SSH الخادم

استخرج بصمة السيرفر وتحقق منها بصيغة SHA256 لحماية اتصالك من الهجمات.

🛡️
التحقق المستقل ضروري للأمان:

لا تعتمد البصمة إلا بعد التأكد من مطابقتها مع ما يظهره خادم Contabo في لوحة التحكم.

الخطوة 4: إعداد مستخدم النشر saaddeploy والمفاتيح

توليد مفتاح Ed25519 محلي وتهيئة مستخدم النشر المحدود في السيرفر.

الخطوة 5: اختبار الجاهزية الشاملة للنشر

التأكد من اكتمال كافة المتطلبات وتفعيل زر النشر الآمن بضغطة واحدة.

⏳ استجابة الموقع المباشر (saadstudio.app)
⏳ Workflow النشر موجود وقابل للقراءة
⏳ GitHub Secrets المطلوبة موجودة
